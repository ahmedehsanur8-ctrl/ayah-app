# সহজ আরবি audio

Qari recordings for the Learn Arabic lessons go here, named exactly as in `docs/ARABIC_AUDIO_LIST.md` (e.g. `name_02_ba.mp3`, `02_ba_a.mp3`, `w_khalaqa.mp3`).
The app plays a file only when it exists here; otherwise it shows "অডিও শীঘ্রই". No synthetic (AI) voice is used for Arabic.
